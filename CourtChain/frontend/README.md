# Frontend CourtChain

Hồ Tuấn Minh · HE191253 · SE1990NJ

React + TypeScript + Vite. Chạy `npm ci`, `npm run dev`; mở http://127.0.0.1:5173.
Backend cần chạy tại http://localhost:5000. Vite proxy `/api` tới backend.

Từng UC được tách ở `src/features/uc51-register-facility` đến `uc55-create-pricing`; trang giới thiệu ở `src/pages/Introduction.tsx`.

Build: `npm run build`. Browser test: `npx playwright test`.
Xem README ở thư mục gốc để chạy toàn bộ ứng dụng.
